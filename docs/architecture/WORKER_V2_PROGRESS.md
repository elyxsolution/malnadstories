## Upcoming Work

- **Frozen Product phase remainder (WBS 6.2.1–6.2.3):** the processing-profile REGISTRY (Classic/Premium/Luxury/Archive/Draft profiles owning render/processing params — Rec 7), pricing versions, and vendor-profile data — all further catalog-like immutable values; the compatibility matrix (`@workerv2/product`) already names profiles as opaque tokens, so wiring the registry is additive.
- **Frozen Blueprint phase remainder**: layout/template/theme RESOLVERS + font/sticker-pack catalogs — these now have their CONTRACT: they implement `SourceResolver` (`@workerv2/product`) in the resolver chain, producing `BlueprintSource` — + Blueprint/Template/Theme version freezing into the version registry.
- **Frozen Render phase (Phase 8) — compositor + document model + PDF exporter DONE, more exporters remaining:** task-phase 15 delivered `@workerv2/composition` (Blueprint-surface → page-Artifact compositor), task-phase 16 delivered `@workerv2/document` (rendered pages → format-independent Document), and task-phase 17 delivered `@workerv2/pdf-export` (Document → deterministic PDF Artifact + descriptor, a normal SDK processor). Remaining: (a) additional **export processors** — preview images, print packages, archival formats — each an independent Processor-SDK processor consuming the same immutable `Document` (same architecture as the PDF exporter; the Document Platform is unaware of them); (b) binding the `surface.render`/`album.assemble` processor NAMES (from the Manifest, ADR-0010) to processors that drive the composition engine + document builder + exporters, honoring `config.surface`/`config.surfaces`, producing write-once artifacts (INV-3: a manifest + artifact store are the only inputs). Once the render/assemble processors are registered into the adapter's resolver, a real album run executes end-to-end (lifting RSK-1).
- **Distributed / durable driving adapters (post task-phase 11):** the single-process Execution Adapter (`@workerv2/execution-adapter`, ADR-0012) now drives the pure Coordinator (effect loop, processor dispatch/resolution, the concrete capability negotiator, session persist+publish, replaceable journal/event seams). Remaining, all additive behind the SAME seams: a **durable** `JournalStore` (SQL/KV) + **bus/queue-backed** `EventSink`, a **distributed/parallel** driver, richer semver-range capability negotiation, and one-active-run (INV-6) enforcement via the Control Plane's Run Registry before a session is created.
- **Concrete processors + pixel backend (the injected work):** task-phase 12 shipped the Processor SDK, task-phase 13 the six deterministic image **foundation** processors (`@workerv2/image-processors`), and task-phase 14 the **pixel backend** (`@workerv2/image-backend`: the `ImageBackend` contract + deterministic reference backend + Pixel Gateway + contract suite). Remaining on the image side: (a) **wire the foundation processors' normalization PLANS to real pixel work** via the Pixel Gateway — decode → resize/rotate/crop/colour → produce a sanitized print master + derivatives; (b) a **native codec-decode backend** (JPEG/PNG/HEIC → pixels + high-throughput transforms) behind the SAME `ImageBackend` contract, validated by `runImageBackendContract`; (c) the **surface-render / album-assemble** (frozen Render phase, M10) processors. Once these land and are registered into the adapter's resolver, a real album run executes end-to-end (this is what finally lifts RSK-1).
- **Deferred infra implementations (now narrowed after the Artifact Platform):** a **durable** persistence backend (SQL/KV) and a **durable** `BlobStore`/registry (object storage) — both drop-in swaps behind the existing contracts (the reusable `runArtifactStoreContract` suite proves a new backend). The content-addressed byte store, addressing, streaming, integrity, registry, validation, and provenance are now **done** (ADR-0006).
- **Storage-side Asset Lifecycle wiring (WBS 5.2.2 remainder):** connecting artifact writes to audited asset-state transitions happens when a producing pipeline exists (image/render phases) — the Control Plane transitions + artifact substrate are both ready.
